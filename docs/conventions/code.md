# Code conventions

Стек и слои: [architecture.md](../specs/architecture.md), решения: [decisions.md](../decisions.md).

## HTML

- Семантика: `header`, `nav`, `main`, `section`, `footer`.
- Один `h1` на страницу; логичная иерархия заголовков.
- У значимых изображений — осмысленный `alt`; декоративные скрыты от скринридеров.
- Без скриншотов вместо разметки блоков.

## CSS

- BEM-классы; design tokens через CSS custom properties.
- Темы: переключение на корне (`data-theme` / класс), без дублирования всей вёрстки.
- Без Bootstrap и прочих CSS-фреймворков.
- Адаптив проверять на 1440 / 768 / 380 и промежутках; без горизонтального скролла.

## JavaScript

- Чистый JS (ES modules допустимы).
- Без TypeScript, jQuery, Swiper и UI-библиотек.
- Часть 2: данные каталога в `data/`; карточка и модалка из одного объекта.
- Без `alert` / `prompt` / `confirm` для обязательной логики.

## Запрещено (штраф курса −100)

- Запрещённый стек из общих требований задания.
- Замена страницы или блоков скриншотами.
