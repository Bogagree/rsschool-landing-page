# Spec: Landing Page (RS School)

Источник: [tasks/landing-page](https://github.com/rolling-scopes-school/tasks/tree/master/fullstack-engineering/tasks/landing-page).

## Цель

Двухстраничный адаптивный сайт (главная + каталог) с темами и интерактивностью на чистом JS.

## Часть 1 — вёрстка

- Две страницы с разными URL, общий header/footer, favicon.
- Главная: ≥ 4 контентных секций (hero, слайдер ≥ 3 слайда, ещё ≥ 2).
- Каталог: ≥ 3 категории; в одной ≥ 8 карточек; кнопка «ещё» или пагинация.
- Адаптив 1440px → 380px; бургер-кнопка ≤ 768px (без открытия).
- Светлая/тёмная тема + `localStorage`.
- Валидный семантический HTML, hover, плавные якоря.

## Часть 2 — функциональность

- Бургер-меню (обе страницы).
- Слайдер/карусель.
- Данные каталога из `.js`/`.json`, динамический рендер.
- Категории, show more / пагинация.
- Модалка + ≥ 2 параметра с обновлением данных без reload.

## Вне скоупа этой подготовки

Реализация HTML/CSS/JS лендинга — отдельная сессия в ветке `landing-page`.
