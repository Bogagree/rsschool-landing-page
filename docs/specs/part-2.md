# Part 2 — Функциональность

Канон: [README-part-2.md](https://github.com/rolling-scopes-school/tasks/blob/master/fullstack-engineering/tasks/landing-page/README-part-2.md).  
Макс. балл: **100**. План шагов: [part-2-plan.md](../part-2-plan.md).

## Scope

- Данные каталога: массив объектов в `data/*.js|json`; карточки рендерятся из JS.
- Карточка и модалка из **одного** объекта (без дублей в HTML).
- Бургер-меню на обеих страницах (≤768).
- Слайдер/карусель (≥ 3), циклический, с анимацией.
- Категории + show-more или pagination (с учётом ширины).
- Модалка + ≥ 2 параметра с live-обновлением связанной информации.

## Out of scope

- Новые страницы / смена стека
- Библиотеки слайдеров и модалок

## Критерии (резюме)

| Блок | Баллы |
| --- | --- |
| Работа с данными | 10 |
| Бургер-меню | 20 |
| Слайдер | 20 |
| Категории | 12 |
| Show-more / pagination | 13 |
| Модалка | 12 |
| Параметры карточки | 13 |

Штрафы: запрещённый стек / скриншоты → **−100**.
