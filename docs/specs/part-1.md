# Part 1 — Вёрстка

Канон: [README-part-1.md](https://github.com/rolling-scopes-school/tasks/blob/master/fullstack-engineering/tasks/landing-page/README-part-1.md).  
Макс. балл: **100**. План шагов: [part-1-plan.md](../part-1-plan.md).

## Scope

- Две страницы с разными URL, переход между ними, favicon.
- Единые header (лого, nav, theme toggle, burger-кнопка ≤768) и footer.
- Главная: ≥ 4 контентных секций — hero, слайдер (≥ 3 слайда + controls), ≥ 2 ещё.
- Каталог: ≥ 3 категории, ≥ 8 карточек в одной, UI show-more или pagination.
- Адаптив 1440 → 380; светлая/тёмная тема + `localStorage`.
- Hover, плавные якоря, валидный семантический HTML.

## Out of scope (Часть 2)

- Открытие бургер-меню
- Логика слайдера
- Переключение категорий / show-more / модалка / параметры

## Критерии (резюме)

| Блок | Баллы |
| --- | --- |
| Страницы и навигация | 10 |
| Обязательные элементы | 25 |
| Визуальное оформление (1440/768/380 × 2 стр.) | 18 |
| Адаптивность | 15 |
| Темы | 17 |
| Валидность / семантика / a11y | 10 |
| Ссылки и hover | 5 |

Штрафы: запрещённый стек / скриншоты вместо вёрстки → **−100**.
